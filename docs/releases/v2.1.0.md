# focus v2.1.0

Teclas más simples y sincronización desde la app.

## Qué cambió

- **Teclas simplificadas:** ahora se usa todo con flechas, Enter, Esc, `?` y Tab. Se sacaron las teclas sueltas (como `q`, `a`, `d`, `e`, `r`, `m`, `p`, `1`-`4` y `+`/`-`).
- **Listas con fila «+ …»:** para crear rutinas, meditaciones, sonidos o presets. Enter sobre un ítem abre su menú con las acciones.
- **Menú Opciones en Focus (Tab):** Timer, deep work, Cargar preset, Volumen general, Pausar/Seguir todo, Apagar todo, Volver al inicio y Salir. Se sacó el panel de presets de Focus.
- **Salir desde el Inicio:** una fila «Salir» con Seguir escuchando de fondo, Apagar todo y salir, o Volver.
- **Configuración › Sincronización:** Conectar Google Drive, Sincronizar y Verificar archivos desde la app, con el avance en vivo.

## Instalar

Debian, Ubuntu o Mint:

```sh
sudo apt install ./focus_2.1.0-1_amd64.deb
```

Si `focus` estaba abierto o sonando en background, corré `focus quit` antes de abrir la versión nueva.

Windows 10 (1803 o más nuevo): bajá `focus-windows-x86_64.exe` y ponelo en el `PATH`.
