# focus v0.2.0 (prerelease, antes v1.0.0)

**focus** (WorkHub) es un mezclador de ambientes para concentrarte, en la terminal, sin tener YouTube abierto.

## Qué trae

- **Menú WorkHub**: al abrir `focus` elegís entre continuar tu última rutina, elegir otra, ir a Focus o la configuración.
- **Focus**: mezclá tus sonidos (los agregás vos desde un link; la app arranca vacía) con volumen por sonido, guardá presets y poné un temporizador que baja el sonido y te avisa al terminar.
- **Modo deep work**: con `d` queda solo el reloj grande.
- **Rutinas**: una lista de tareas que vas marcando, más una meditación guiada opcional que se marca sola al terminar.
- **Meditaciones**: lista aparte, agrupada por duración.
- **Sincronización con Google Drive**: `focus sync` sube y baja tus listas y audios. La primera vez prepara rclone solo.

## Instalar

Debian, Ubuntu o Mint:

```sh
sudo apt install ./focus_1.0.0-1_amd64.deb
```

`rclone`, `yt-dlp` y `ffmpeg` vienen como recomendados. El `yt-dlp` de Debian puede ser viejo; si falla al bajar audios, actualizalo.

Windows 10 (1803 o más nuevo): bajá `focus-windows-x86_64.exe` y ponelo en el `PATH`.

Si actualizás desde una versión anterior, corré `focus quit` una vez.
