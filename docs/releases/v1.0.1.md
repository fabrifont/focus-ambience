# focus v1.0.1 (prerelease)

Arreglo de fluidez: la interfaz ahora responde al instante cuando apretás una tecla.

## Qué cambió

- **Teclas instantáneas**: antes una tecla podía tardar hasta medio segundo en verse; ahora se redibuja apenas llega, y también apenas el audio avisa algo.
- Si apretás muchas teclas seguidas (o dejás una apretada), se aplican todas juntas y se dibuja una sola vez.
- El audio en background ya no arma ni manda el estado cuando no hay ninguna terminal conectada.
- La animación de Focus ya no hace una copia de texto por cada sonido en cada cuadro.

## Instalar

Debian, Ubuntu o Mint:

```sh
sudo apt install ./focus_1.0.1-1_amd64.deb
```

Si `focus` estaba abierto o sonando en background, corré `focus quit` antes de abrir la versión nueva.

Windows 10 (1803 o más nuevo): bajá `focus-windows-x86_64.exe` y ponelo en el `PATH`.
