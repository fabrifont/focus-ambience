# focus v2.1.1

Focus primero en el menú de inicio.

## Qué cambió

- **Inicio:** «Ir a Focus» ahora es la primera opción y el cursor arranca ahí. Después vienen Continuar la rutina (o Crear mi primera rutina), Elegir otra rutina, Configuración y Salir. Los textos y lo que hace cada opción no cambiaron.

## Instalar

Debian, Ubuntu o Mint:

```sh
sudo apt install ./focus_2.1.1-1_amd64.deb
```

Si `focus` estaba abierto o sonando en background, corré `focus quit` antes de abrir la versión nueva.

Windows 10 (1803 o más nuevo): bajá `focus-windows-x86_64.exe` y ponelo en el `PATH`.
