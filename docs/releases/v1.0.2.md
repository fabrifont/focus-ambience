# focus v1.0.2

Versión de mantenimiento: la app funciona igual que la v1.0.1.

## Qué cambió

- Las releases ahora salen como versión final por defecto, no como prerelease.
- Las notas de la v1.0.1 ya no dicen «prerelease».

## Instalar

Debian, Ubuntu o Mint:

```sh
sudo apt install ./focus_1.0.2-1_amd64.deb
```

Si `focus` estaba abierto o sonando en background, corré `focus quit` antes de abrir la versión nueva.

Windows 10 (1803 o más nuevo): bajá `focus-windows-x86_64.exe` y ponelo en el `PATH`.
