# focus v0.4.1

Nueva numeración: focus todavía está en desarrollo, así que las versiones pasan a ser 0.x.y. Esta es la misma app que la v2.1.1, con el número nuevo.

## Qué cambió

- **Números de versión:** v1.0.x ahora es v0.2.x, v2.0.0 es v0.3.0, v2.1.0 es v0.4.0 y v2.1.1 es esta v0.4.1. La app funciona igual.
- **Paquete .deb:** la versión del paquete es `1:0.4.1-1`. El `1:` adelante hace que apt la tome como más nueva que la 2.1.1 que ya tenías, así que se actualiza sin desinstalar nada.
- **Inicio** (viene de la v2.1.1): «Ir a Focus» es la primera opción y el cursor arranca ahí.

## Instalar

Debian, Ubuntu o Mint:

```sh
sudo apt install ./focus_0.4.1-1_amd64.deb
```

Si `focus` estaba abierto o sonando en background, corré `focus quit` antes de abrir la versión nueva.

Windows 10 (1803 o más nuevo): bajá `focus-windows-x86_64.exe` y ponelo en el `PATH`.
